# Countries Module Overview

Countries merupakan Master Data utama yang menyimpan informasi seluruh negara yang digunakan dalam sistem.

Data Countries menjadi referensi bagi berbagai modul lain seperti Ports, Currency, News, Weather, Risk Analysis, Shipment Analysis, Dashboard Analytics, dan Reporting.

Countries tidak menyimpan data operasional, tetapi hanya menyimpan informasi dasar setiap negara.

---

# Business Objective

Modul Countries dibangun untuk menyediakan data negara yang valid, konsisten, dan mudah dikelola.

Data Countries digunakan sebagai referensi utama bagi.

- Ports
- Currency
- News
- Weather
- Risk Analysis
- Shipment Analysis
- Dashboard Analytics
- Reporting

Seluruh data operasional akan mengacu kepada Countries sebagai Master Data.

---

# Functional Requirements

Administrator dapat melakukan.

- Melihat daftar Countries
- Menambah Country
- Mengubah Country
- Menghapus Country
- Melakukan pencarian
- Mengurutkan data
- Menggunakan Pagination

---

# Non Functional Requirements

Countries Module harus memenuhi standar berikut.

Performance

- Optimized Query
- Pagination
- Database Index

Security

- Authentication
- Authorization
- CSRF Protection
- Request Validation
